# Paper Zone

Браузерная игра о захвате территории в духе Paper.io 2: персонаж едет за курсором
в любую сторону, за ним тянется след, вернулся на свою землю — всё внутри петли
твоё. Подрезали хвост — проиграл.

Чистый HTML + CSS + JavaScript, Canvas 2D, Web Audio, localStorage. Без сервера,
регистрации и внешних API.

**Версия 2.0:** аналоговое управление на 360°, десять полноценных персонажей,
переработанная графика и интерфейс.

---

## Как запустить

**Способ 1 — просто открыть файл.** Двойной щелчок по `index.html`. Игра работает
с `file://`: скрипты подключены классическими `<script>`, без ES-модулей и `fetch`.

**Способ 2 — локальный сервер** (если нужен адрес для телефона в той же сети):

```bash
npm run dev          # http://127.0.0.1:4173/
```

Node нужен только для сервера, тестов и проверок; для самой игры — нет.

## Управление

| Действие | Компьютер | Телефон |
|---|---|---|
| Движение | курсор мыши — персонаж едет в его сторону и плавно поворачивает | палец задаёт направление свайпа, вести можно где угодно |
| Альтернатива | WASD или стрелки (включая диагонали) | — |
| Пауза | `Esc` или `P`, кнопка ⏸ в HUD | кнопка ⏸ |
| Заново после матча | `R` или «Играть снова» | «Играть снова» |

Персонаж никогда не телепортируется к курсору: он разворачивается с ограниченной
угловой скоростью (≈8.2 рад/с) и всегда едет с постоянной скоростью — диагональ
не быстрее прямой. Держи курсор близко к персонажу, чтобы закладывать крутые
петли, и дальше — для длинных прямых, как в оригинале.

## Персонажи

Десять скинов, у каждого свой силуэт, материал, палитра территории и анимация:

| | | |
|---|---|---|
| **Мята** — слизь с бликом | **Астронавт** — шлем с визором и антенной | **Робот** — металл, визор-полоса, болты |
| **Пламя** — языки огня, пульсация | **Кристалл** — гранёный камень с бликами | **Разряд** — электрический силуэт |
| **Дрон** — корпус с пропеллерами | **Желе** — полупрозрачная капля с пузырями | **Неон-кот** — уши, усы, светящиеся глаза |
| **Призрак** — волнистый низ, дымка | | |

Скин выбирается в меню: слева — большая живая сцена, справа — карточки с
превью (рисуются тем же кодом, что и в игре). Выбор сохраняется в localStorage.

## Режимы

| Режим | Правила |
|---|---|
| **Классика** | против 5 ботов; победа — 30% карты. Погибшие боты возвращаются через несколько секунд, арена не пустеет |
| **Выживание** | старт с 3 ботами, каждые 16 секунд прибывает новый (до 7), к 70-й секунде они злее; победа — продержаться 150 секунд |
| **Быстрый матч** | 90 секунд, 5 ботов; в конце сравнивается ваш процент с лучшим у соперника |
| **Свободная игра** | 0–7 ботов, карта 120×120 / 160×160 / 220×220, скорость 9–18 клеток/с |

Сложность (Лёгкий / Средний / Сложный) меняет у ботов риск, агрессию, зрение и
частоту решений, а не только скорость.

## Механика

1. **Своя земля — безопасна.** На ней нельзя погибнуть, в том числе в лобовом.
2. **След.** Первая клетка вне своей земли открывает след; он рисуется по
   фактической траектории, без разрывов даже при низком FPS.
3. **Замыкание.** Вернувшись на свою землю, забираешь всё, что отрезано от
   внешней границы: границей служат след, своя земля и край карты. Форма петли
   любая — вогнутая, с самопересечением, у самого края.
4. **Смерть.** Свой след — смерть. Чужой след — оружие: пересекли его, и владелец
   погибает. Край карты смертелен. Лобовое вне своей земли убивает обоих.
5. **Площадь.** Считается по фактическим клеткам: `клетки игрока / свободные
   клетки карты`. Уже своя клетка не начисляется повторно.

Подробный разбор правил и отличий от оригинала — в [`GAME_ANALYSIS.md`](GAME_ANALYSIS.md),
исследование управления и стиля — в [`VISUAL_AND_CONTROLS_ANALYSIS.md`](VISUAL_AND_CONTROLS_ANALYSIS.md).

## Настройки и сохранения

Настройки — экран «Настройки» из меню или из паузы: звук, мини-карта, тряска
экрана, громкость. Рекорды — экран «Рекорды»: матчи, победы, поражения, доля
побед, лучший процент, лучший счёт, уничтоженные боты, лучшее выживание.

Всё лежит в `localStorage` под ключом `paperzone.save.v1`, при загрузке данные
проверяются и приводятся к безопасным значениям. Если хранилище недоступно
(приватный режим), игра работает с прогрессом в памяти и не падает. Сброс
прогресса требует второго нажатия в течение 4 секунд.

Это **локальные** рекорды. Онлайн-рейтинга и синхронизации между устройствами нет.

## Тесты и проверки

```bash
npm test        # 41 тест логики в Node
npm run check   # 55 интеграционных проверок в реальном браузере × 2 вьюпорта
npm run shots   # скриншоты в docs/
```

`npm test` — `node --test`, ничего устанавливать не нужно (Node 18+). Покрытие:
физика движения (произвольные углы, диагональ без ускорения, ограничение поворота,
непрерывность следа при 10 FPS, петля без смерти, границы, лобовые), захват
(простые, вогнутые, большие и краевые контуры, отсутствие дыр, перехват чужой
территории, проценты), матч (старт, 45 секунд симуляции ботов, три уровня
сложности, респавн ботов, детерминизм по seed, победы и поражения во всех режимах).

`npm run check` собирает копию `index.html` с внедрённым `tools/selftest.js`,
запускает headless Edge на 1342×808 и 390×760, кликает по настоящим кнопкам,
**водит настоящий указатель** (PointerEvent) вокруг головы, проверяет что курс
следует за ним, замыкает петлю, ставит паузу, меняет настройки, доводит матч до
результата и проверяет отрисованный канвас по пикселям.

```
paper-io-2/
├── index.html               экраны, HUD, подключение скриптов
├── style.css                «бумажная» тема, адаптив, мобильные медиазапросы
├── src/
│   ├── core.js              сетка, тонкий след по отрезку, заливка контура
│   ├── skins.js             10 персонажей: силуэт, палитра, отрисовка, анимация
│   ├── player.js            сущность игрока: курс, след, «зона прощения»
│   ├── ai.js                боты: цели, оценка 24 курсов, три уровня
│   ├── engine.js            матч: непрерывное движение, столкновения, респавн
│   ├── renderer.js          арена, территория, следы, персонажи, эффекты
│   ├── input.js             мышь/палец/клавиатура → угол
│   ├── audio.js             синтез звуков на Web Audio
│   ├── storage.js           сохранения с проверкой данных
│   ├── ui.js                меню, выбор скина, HUD, настройки, результаты
│   └── main.js              цикл, экраны, события, связка модулей
├── tests/                   physics / game / territory (node --test)
├── tools/                   dev-server, selftest, headless-check, shot
├── docs/                    скриншоты и status.md
├── GAME_ANALYSIS.md         правила, источники, технические решения
├── VISUAL_AND_CONTROLS_ANALYSIS.md  управление и стиль: исследование
└── README.md
```

`core.js`, `skins.js`, `player.js`, `ai.js`, `engine.js` не зависят от DOM: те же
файлы грузятся в браузере и в Node, поэтому правила проверяются без браузера.

## Что реализовано

- Аналоговое управление на 360° с ограниченной угловой скоростью, мышь, палец и клавиатура.
- След по фактической траектории без разрывов; заливка контура от внешней границы.
- Десять персонажей с индивидуальной формой, палитрой и анимацией; живой выбор в меню.
- Боты с целями, уклонением, атакой чужого следа и респавном.
- Четыре режима, пауза, экран результатов с настоящими числами, рекорды.
- Оформление: бумажная арена, территории с контуром и тенью, светящийся след,
  частицы, мини-карта, тряска, адаптив под телефон и ландшафт.
- Звук (синтез), сохранение настроек и прогресса.

## Что не реализовано

- **Сетевой мультиплеер.** Его нет и он не имитируется ботами: в интерфейсе нигде
  не написано «онлайн».
- Онлайн-рейтинг, аккаунты, облачные сохранения.
- Музыка, достижения, скины за прогресс.

## Известные ограничения

- Боты играют агрессивно и часто гибнут друг о друга; они возвращаются, но их
  территории растут медленнее, чем у аккуратного игрока.
- FPS на реальном телефоне не измерялся (headless-браузер не даёт частоту кадров).
- Толщина следа подобрана под читаемость: касание считается по «ядру» головы,
  поэтому у самой кромки следа смерть не мгновенная.
