# Paper Zone

Браузерная игра о захвате территории в духе Paper.io 2: уходишь со своей земли — тянешь след, возвращаешься — забираешь всё, что внутри петли. Подрезали хвост — проиграл.

Чистый HTML + CSS + JavaScript, Canvas 2D, Web Audio, localStorage. Без сервера, регистрации, рекламы и внешних API.

---

## Как запустить

**Способ 1 — просто открыть файл.** Двойной щелчок по `index.html`. Игра работает с `file://`: скрипты подключены классическими `<script>`, без ES-модулей и без `fetch`, поэтому ничего не блокируется.

**Способ 2 — локальный сервер** (если удобнее или нужен адрес для телефона в той же сети):

```bash
npm run dev          # http://127.0.0.1:4173/
PORT=5000 npm run dev
```

Сервер — это `tools/dev-server.js` на стандартной библиотеке Node, зависимостей нет. Node нужен только для сервера, тестов и проверок; для самой игры — нет.

## Управление

| Действие | Клавиатура / мышь | Телефон |
|---|---|---|
| Движение | WASD или стрелки, либо вести курсором мыши | провести пальцем в нужную сторону (джойстик появляется под пальцем) |
| Пауза | `Esc` или `P`, кнопка ⏸ в HUD | кнопка ⏸ |
| Заново после матча | `R` или кнопка «Играть снова» | кнопка «Играть снова» |

Разворот на 180° запрещён, пока тянется след. Движение — по четырём направлениям.

## Режимы

| Режим | Правила |
|---|---|
**Классика** | против 5 ботов. Победа — 60% карты или уничтожение всех соперников. Смерть — поражение.
**Выживание** | старт с 3 ботами, каждые 16 секунд прибывает новый (до 7), к 70-й секунде они становятся агрессивнее. Победа — продержаться 150 секунд.
**Быстрый матч** | 90 секунд, 5 ботов. В конце сравнивается ваш процент с лучшим процентом соперника.
**Свободная игра** | свои настройки: 0–7 ботов, карта 90×90 / 140×140 / 200×200, скорость 7–16 клеток в секунду.

Сложность (Лёгкий / Средний / Сложный) меняет у ботов риск, агрессию, дальность зрения и частоту решений, а не только скорость.

## Механика

1. **Своя земля — безопасна.** На ней нельзя погибнуть, в том числе от лобового столкновения.
2. **След.** Первая клетка вне своей земли открывает след; каждая пройденная клетка добавляется в него.
3. **Замыкание.** Вернувшись на свою землю, вы забираете всё, что отрезано от внешней границы: границей служат ваш след, ваша земля и край карты. Форма петли любая — вогнутая, с самопересечением, у самого края.
4. **Смерть.** Свой след — смерть. Чужой след — оружие: пересекли его, и владелец погибает. Край карты смертелен. Лобовое вне своей земли убивает обоих.
5. **Площадь.** Считается по фактическим клеткам: `клетки игрока / свободные клетки карты`. Уже своя клетка не начисляется повторно.

Подробный разбор правил, источников и отличий от оригинала — в [`GAME_ANALYSIS.md`](GAME_ANALYSIS.md).

## Настройки и сохранения

Настройки — экран «Настройки» из меню или из паузы: звук вкл/выкл, громкость, мини-карта, тряска экрана. Рекорды — экран «Рекорды»: матчи, победы, поражения, доля побед, лучший процент, лучший счёт, уничтоженные боты, лучшее время выживания.

Всё лежит в `localStorage` под ключом `paperzone.save.v1`. При загрузке данные проверяются и приводятся к безопасным значениям; если хранилище недоступно (приватный режим), игра продолжает работать с прогрессом в памяти и не падает. Кнопка «Сбросить прогресс» просит подтверждение вторым нажатием в течение 4 секунд.

Это **локальные** рекорды. Онлайн-рейтинга и синхронизации между устройствами нет.

## Тесты и проверки

```bash
npm test        # 39 тестов логики в Node (территория, столкновения, матч)
npm run check   # 51 интеграционная проверка в реальном браузере × 2 вьюпорта
```

`npm test` — это `node --test`, ничего устанавливать не нужно (Node 18+). Покрытие: захват простых, вогнутых, больших и краевых контуров с проверкой конкретных клеток; отсутствие дыр; перехват чужой территории; проценты; все виды смерти; лобовые и обмен клетками; 45 секунд симуляции ботов; детерминизм по seed; победы и поражения во всех режимах.

`npm run check` собирает копию `index.html` с внедрённым `tools/selftest.js`, запускает headless Edge (или Chrome) на 1342×808 и на 390×760, кликает по настоящим кнопкам, ведёт персонажа клавиатурой, замыкает контур, ставит паузу, меняет настройки, доводит матч до результата и проверяет отрисованный канвас по пикселям. Отчёт печатается в консоль, при падении — код выхода 1. Путь к браузеру можно задать в `PZ_BROWSER`.

## Структура

```
paper-io-2/
├── index.html            экраны, HUD, подключение скриптов
├── style.css             оформление, адаптив, мобильные медиазапросы
├── package.json          только скрипты, без зависимостей
├── src/
│   ├── core.js           сетка, следы, алгоритм захвата, палитры
│   ├── ai.js             боты: состояния, оценка направлений, сложность
│   ├── engine.js         матч: движение, столкновения, режимы, итог
│   ├── renderer.js       камера, растр территории, следы, эффекты, мини-карта
│   ├── input.js          клавиатура, мышь, сенсорный джойстик
│   ├── audio.js          синтез звуков на Web Audio
│   ├── storage.js        сохранения с проверкой данных
│   ├── ui.js             меню, HUD, настройки, результаты, рекорды
│   └── main.js           цикл, экраны, события, связка модулей
├── tests/                territory / collision / game (node --test)
├── tools/
│   ├── dev-server.js     статический сервер без зависимостей
│   ├── selftest.js       сценарий браузерной проверки
│   └── headless-check.js запуск проверки в headless Edge/Chrome
├── GAME_ANALYSIS.md      исследование Paper.io 2 и технические решения
└── README.md
```

`core.js`, `ai.js`, `engine.js` не зависят от DOM: те же файлы грузятся в браузере и в Node, поэтому правила проверяются без браузера.

## Что реализовано полностью

- Захват территории заливкой от внешней границы: вогнутые контуры, самопересечения, край карты, чужая земля внутри петли.
- Точный подсчёт клеток и процента, без повторных начислений.
- Движение с фиксированным шагом, независимое от FPS, с сенсорным и мышиным управлением.
- Боты с шестью состояниями и тремя уровнями сложности, которые расширяются, возвращаются, уклоняются и атакуют чужой след.
- Все виды смерти, лобовые столкновения, освобождение территории ботов.
- Четыре режима с разными правилами, пауза, экран результатов с настоящими числами.
- Меню, настройки, рекорды, сохранение прогресса и настроек.
- Звук (синтез), эффекты захвата и смерти, мини-карта, тряска экрана, адаптив под телефон и ландшафт.

## Что не реализовано

- **Сетевой мультиплеер.** Его нет и он не имитируется ботами: в интерфейсе нигде не написано «онлайн». Серверная авторитетная симуляция — отдельная задача.
- Онлайн-рейтинг, аккаунты, облачные сохранения.
- Аналоговое (не по сетке) движение, как в Paper.io 2, и круглая арена — см. обоснование в `GAME_ANALYSIS.md`.
- Достижения, скины за прогресс, музыка.

## Известные ограничения

- Баланс ботов — эвристика; на лёгком уровне боты иногда гибнут от чужих следов чаще, чем на среднем.
- FPS на реальном телефоне не измерялся (headless-браузер не даёт частоту кадров устройства).
- Звук простой, без музыки.
