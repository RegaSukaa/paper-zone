🎮 **Paper Zone — готово**

Папка: `C:\Users\Rubin\Desktop\paper-io-2`

Браузерная игра о захвате территории в духе Paper.io 2 на чистом HTML/CSS/JS (Canvas 2D, Web Audio, localStorage). Открывается двойным щелчком по `index.html` — сервер, регистрация и интернет не нужны.

**Что внутри**
• Захват: заливка от внешней границы — вогнутые петли, самопересечения, край карты, чужая земля внутри контура.
• Боты: 6 состояний (расширение, патруль, возврат, уклонение, атака, защита) и 3 уровня; сложность меняет риск, агрессию, зрение, а не только скорость.
• 4 режима: классика (60% карты или все соперники), выживание (150 с, соперники прибывают), быстрый матч (90 с), свободная игра (0–7 ботов, карта до 200×200, скорость).
• Интерфейс: меню, HUD, пауза, настройки (звук, громкость, мини-карта, тряска), экран результатов с настоящими числами, рекорды.
• Управление: WASD/стрелки, мышь, свайп/джойстик на телефоне; Esc — пауза, R — заново.

**Проверено реально**
• 39/39 тестов логики: `npm test` (территория, столкновения, матч, боты, детерминизм по seed).
• 51/51 интеграционная проверка в headless Edge на 1342×808 и 390×760, 0 ошибок JS — два прогона подряд зелёные.
• Тесты нашли 8 багов, все исправлены (выброс из настроек в меню из-за атрибута на body; смерть игрока, стоящего на своей земле; зависание перезапуска и др.).

**Не сделано (честно)**
• Сетевого мультиплеера нет — боты не выдают себя за онлайн, в интерфейсе он нигде не обещан.
• Движение по сетке (4 направления), а не аналоговое, как в Paper.io 2 — компромисс ради точного и проверяемого захвата, обосновано в GAME_ANALYSIS.md.
• Онлайн-рейтинга, аккаунтов, музыки нет.

**Команды**
`npm test` — 39 тестов · `npm run check` — браузерные проверки · `npm run dev` — локальный сервер (не обязателен)

Документы: README.md, GAME_ANALYSIS.md (исследование + решения), docs/status.md (что сделано и чем проверено).
